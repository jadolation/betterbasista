# Better Basista — HTML/CSS Starter Template

A starter static site for Better Basista, following the general civic-transparency structure and visual language of BetterGov.ph BetterLGU portals while using the content supplied in the Better Basista Website Content & Structure Guide.

## Files

- `index.html` — homepage
- `about.html` — About Us page
- `projects.html` — Projects & Tools page
- `volunteer.html` — Volunteer page
- `styles.css` — shared styling
- `assets/better-basista-logo.svg` — temporary flat blue/gold graphical logo used by the template

## Notes

1. Replace `assets/better-basista-logo.svg` with the final approved Better Basista logo when ready.
2. The template intentionally uses HTML + CSS only; no JavaScript framework or backend is included.
3. Project cards on the Projects page are placeholders until actual tools and datasets are added.
4. Volunteer submission flow is a placeholder and should be wired to the project's preferred contribution workflow later.
